# Product Requirements Document (PRD)

# AtlasIA

Versión: 1.0

Estado: En planificación

---

# Resumen

AtlasIA es una plataforma SaaS que permite a las empresas crear agentes inteligentes entrenados con la información de su propio negocio.

Su objetivo es automatizar la atención al cliente mediante inteligencia artificial.

---

# Problema

Las pequeñas y medianas empresas responden cientos de preguntas repetitivas cada semana.

Esto genera:

- pérdida de tiempo
- mayores costos
- tiempos de respuesta lentos
- mala experiencia del cliente

---

# Solución

AtlasIA permitirá crear un asistente IA personalizado que responderá únicamente utilizando la información de la empresa.

---

# Público objetivo

• Ecommerce

• Constructoras

• Clínicas

• Estudios jurídicos

• Talleres

• Academias

• Empresas de servicios

---

# Objetivos del producto

• Reducir consultas repetitivas

• Disponibilidad 24/7

• Disminuir costos de soporte

• Centralizar el conocimiento

• Mejorar la experiencia del cliente

---

# Funcionalidades principales

- Gestión de empresas
- Gestión de usuarios
- Agentes IA
- Base de conocimiento
- Chat
- Widget
- Analíticas
- Suscripciones

---

# MVP

La primera versión permitirá:

- Registrar empresa
- Iniciar sesión
- Crear un agente IA
- Configurar el agente
- Subir documentos
- Procesar documentos
- Conversar con el agente
- Publicar un widget
- Visualizar conversaciones
- Consultar analíticas básicas
