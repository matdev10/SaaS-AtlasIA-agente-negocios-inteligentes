# Flujo 01 · Registro

## Objetivo

Permitir que una empresa cree una cuenta en AtlasIA y quede lista para comenzar el proceso de onboarding.

---

## Actor principal

Administrador de empresa.

---

## Entradas

- Nombre de la empresa
- Nombre del administrador
- Correo electrónico
- Contraseña

---

## Proceso

1. El usuario entra a la landing de AtlasIA.
2. Hace clic en "Comenzar gratis".
3. Completa el formulario de registro.
4. El sistema valida los datos.
5. El sistema verifica que el correo no esté registrado.
6. El sistema crea la empresa.
7. El sistema crea el usuario administrador.
8. El sistema asigna un plan inicial.
9. El sistema crea un agente IA principal.
10. El sistema crea la configuración inicial de la empresa.
11. El sistema inicia sesión automáticamente.
12. El usuario es redirigido al onboarding.

---

## Salida esperada

La empresa queda creada correctamente y el usuario administrador puede iniciar el onboarding.

---

## Errores posibles

- Correo ya registrado.
- Contraseña débil.
- Campos obligatorios incompletos.
- Error al crear la empresa.
- Error al crear usuario administrador.
- Error interno del servidor.

---

## Resultado del flujo

Empresa registrada con:

- Usuario administrador
- Plan inicial
- Agente IA principal
- Configuración base
