# Roadmap del Producto

# AtlasIA

Versión: 1.0

Estado: En planificación

---

# Objetivo

Definir la evolución del producto AtlasIA desde el MVP hasta futuras versiones, estableciendo prioridades, dependencias y alcance de cada fase.

---

# Principios del desarrollo

AtlasIA se desarrollará de forma incremental.

Cada fase deberá entregar una funcionalidad completamente operativa antes de avanzar a la siguiente.

Se priorizará:

- simplicidad
- escalabilidad
- seguridad
- experiencia de usuario

---

# MVP (Versión 1.0)

Objetivo:

Permitir que una empresa pueda crear un agente IA funcional y publicarlo en su sitio web.

Incluye:

- Registro de empresa
- Inicio de sesión
- Panel de administración
- Gestión de usuarios
- Creación de un agente IA
- Configuración básica del agente
- Base de conocimiento
- Carga de documentos
- Procesamiento de documentos
- Chat de prueba
- Widget embebible
- Conversaciones
- Dashboard básico
- Plan gratuito

No incluye:

- Marketplace
- API pública
- Integraciones
- WhatsApp
- Slack
- Teams
- CRM
- Multiidioma
- Facturación avanzada

---

# Versión 1.1

Objetivo

Mejorar la experiencia de administración.

Incluye

- Analytics avanzados
- Gestión de conversaciones
- Mejoras del dashboard
- Edición avanzada del agente
- Historial de entrenamiento

---

# Versión 1.2

Objetivo

Automatizar la administración.

Incluye

- Roles avanzados
- Invitación de usuarios
- Auditoría
- Notificaciones
- Gestión avanzada de documentos

---

# Versión 2.0

Objetivo

Convertir AtlasIA en una plataforma de automatización empresarial.

Incluye

- API pública
- Integraciones
- WhatsApp
- Telegram
- Slack
- Microsoft Teams
- CRM
- Automatizaciones
- Webhooks

---

# Dependencias

Orden recomendado:

1. Empresas
2. Usuarios
3. Agentes IA
4. Base de conocimiento
5. Procesamiento
6. Chat
7. Widget
8. Analytics
9. Suscripciones
10. Integraciones

---

# Criterio de finalización del MVP

El MVP se considera terminado cuando una empresa puede:

- registrarse
- iniciar sesión
- crear un agente
- entrenarlo con documentos
- conversar con él
- instalar el widget
- visualizar conversaciones
