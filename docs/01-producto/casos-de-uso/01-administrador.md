# Casos de Uso · Administrador de Empresa

## Descripción

El Administrador de Empresa es el usuario responsable de configurar y administrar AtlasIA para su organización.

Es el principal actor del sistema.

---

# Objetivos

- Configurar AtlasIA.
- Entrenar Agentes IA.
- Gestionar usuarios.
- Consultar estadísticas.
- Administrar la suscripción.
