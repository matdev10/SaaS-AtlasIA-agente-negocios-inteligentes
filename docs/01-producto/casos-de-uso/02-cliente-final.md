# Casos de Uso · Cliente Final

## Descripción

El Cliente Final es la persona que interactúa con el Agente IA mediante el widget instalado en el sitio web de una empresa.

---

# Objetivo

Obtener respuestas rápidas, claras y confiables sin necesidad de contactar a un ejecutivo.
