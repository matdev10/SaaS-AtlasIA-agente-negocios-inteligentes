# Tecnologías de AtlasIA

## Backend

### NestJS

Framework principal del backend.

Se utilizará para construir una API modular, escalable y mantenible.

## Lenguaje

### TypeScript

Permite trabajar con tipado fuerte, mejor organización y menos errores en tiempo de desarrollo.

## Base de datos

### PostgreSQL

Base de datos relacional principal del sistema.

## ORM

### Prisma

Herramienta para modelar la base de datos y trabajar con consultas de forma segura.

## Inteligencia Artificial

### OpenAI API

Se utilizará para generar respuestas inteligentes a partir del conocimiento de cada empresa.

## Búsqueda semántica

### pgvector

Extensión de PostgreSQL para almacenar embeddings y realizar búsqueda semántica.

## Frontend

### Next.js

Se utilizará para crear el panel web, landing page y dashboard de empresas.

## Widget

### JavaScript embebible

Permitirá que cada empresa instale el agente IA en su sitio web mediante un script.
